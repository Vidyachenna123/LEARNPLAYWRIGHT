## About

This repository contains hands-on JavaScript examples and exercises designed to build a solid foundation before diving into Playwright test automation. Each chapter introduces new concepts with simple, easy-to-understand code snippets.

## Prerequisites

- [Node.js](https://nodejs.org/) installed on your machine
- [Visual Studio Code](https://code.visualstudio.com/) (recommended)
- Basic understanding of programming concepts (helpful but not required)

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Vidyachenna123/LEARNPLAYWRIGHT.git
   ```

2. **Navigate to the project folder:**
   ```bash
   cd LEARNPLAYWRIGHT
   ```

3. **Run a JavaScript file:**
   ```bash
   node Chapter_01_Basics/01_basics.js
   ```
