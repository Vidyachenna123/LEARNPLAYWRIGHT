# Visual Studio Code - Default Keyboard Shortcuts (Windows)

> **Tip:** Open the Keyboard Shortcuts editor with `Ctrl + K Ctrl + S`

## General

| Shortcut | Action |
|----------|--------|
| `Ctrl + Shift + P` / `F1` | Command Palette |
| `Ctrl + P` | Quick Open (switch files) |
| `Ctrl + Shift + N` | New window |
| `Ctrl + W` | Close window |
| `Ctrl + ,` | Open Settings |
| `Ctrl + K Ctrl + S` | Open Keyboard Shortcuts |

## Basic Editing

| Shortcut | Action |
|----------|--------|
| `Ctrl + X` | Cut line (empty selection) |
| `Ctrl + C` | Copy line (empty selection) |
| `Ctrl + V` | Paste |
| `Ctrl + Shift + V` | Paste and match style |
| `Ctrl + Z` | Undo |
| `Ctrl + Y` | Redo |
| `Ctrl + K Ctrl + Z` | Toggle Zen Mode |
| `Ctrl + K Z` | Toggle Zen Mode (alternative) |
| `Ctrl + /` | Toggle line comment |
| `Shift + Alt + A` | Toggle block comment |
| `Ctrl + Shift + K` | Delete current line |
| `Alt + Up / Down` | Move line up / down |
| `Shift + Alt + Up / Down` | Copy line up / down |
| `Ctrl + Enter` | Insert line below |
| `Ctrl + Shift + Enter` | Insert line above |
| `Ctrl + ]` | Indent line |
| `Ctrl + [` | Outdent line |
| `Ctrl + D` | Add selection to next find match |
| `Ctrl + Shift + L` | Select all occurrences of current selection |
| `Shift + Alt + Left / Right` | Expand / shrink selection |

## Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl + T` | Show all symbols |
| `Ctrl + G` | Go to line |
| `Ctrl + Shift + O` | Go to symbol in file |
| `Ctrl + Shift + M` | Show problems panel |
| `F8` | Go to next error or warning |
| `Shift + F8` | Go to previous error or warning |
| `Alt + Left` | Go back |
| `Alt + Right` | Go forward |
| `Ctrl + Tab` | Navigate editor group history |

## Search and Replace

| Shortcut | Action |
|----------|--------|
| `Ctrl + F` | Find |
| `Ctrl + H` | Replace |
| `F3` | Find next |
| `Shift + F3` | Find previous |
| `Ctrl + Shift + F` | Search across files |
| `Ctrl + Shift + H` | Replace across files |
| `Ctrl + E` / `Ctrl + Shift + E` | Use selection for find |

## Multi-cursor and Selection

| Shortcut | Action |
|----------|--------|
| `Alt + Click` | Insert cursor |
| `Ctrl + Alt + Up / Down` | Insert cursor above / below |
| `Ctrl + U` | Undo last cursor operation |
| `Shift + Alt + I` | Insert cursor at end of each line selected |
| `Ctrl + I` | Select current line |
| `Ctrl + Shift + \` | Jump to matching bracket |

## Editor Management

| Shortcut | Action |
|----------|--------|
| `Ctrl + W` | Close editor |
| `Ctrl + K W` | Close all editors in group |
| `Ctrl + \` | Split editor |
| `Ctrl + 1 / 2 / 3` | Focus into 1st / 2nd / 3rd editor group |
| `Ctrl + K Ctrl + Left / Right` | Focus previous / next editor group |
| `Ctrl + K Ctrl + Shift + Left / Right` | Move editor left / right |
