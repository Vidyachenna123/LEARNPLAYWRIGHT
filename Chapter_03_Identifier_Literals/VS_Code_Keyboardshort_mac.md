# Visual Studio Code - Default Keyboard Shortcuts (macOS)

> **Tip:** Open the Keyboard Shortcuts editor with `Cmd + K Cmd + S`

## General

| Shortcut | Action |
|----------|--------|
| `Cmd + Shift + P` / `F1` | Command Palette |
| `Cmd + P` | Quick Open (switch files) |
| `Cmd + Shift + N` | New window |
| `Cmd + W` | Close window |
| `Cmd + ,` | Open Settings |
| `Cmd + K Cmd + S` | Open Keyboard Shortcuts |

## Basic Editing

| Shortcut | Action |
|----------|--------|
| `Cmd + X` | Cut line (empty selection) |
| `Cmd + C` | Copy line (empty selection) |
| `Cmd + V` | Paste |
| `Cmd + Shift + V` | Paste and match style |
| `Cmd + Z` | Undo |
| `Cmd + Shift + Z` | Redo |
| `Cmd + K Cmd + Z` | Toggle Zen Mode |
| `Cmd + K Z` | Toggle Zen Mode (alternative) |
| `Cmd + /` | Toggle line comment |
| `Shift + Option + A` | Toggle block comment |
| `Cmd + Shift + K` | Delete current line |
| `Option + Up / Down` | Move line up / down |
| `Option + Shift + Up / Down` | Copy line up / down |
| `Cmd + Enter` | Insert line below |
| `Cmd + Shift + Enter` | Insert line above |
| `Cmd + ]` | Indent line |
| `Cmd + [` | Outdent line |
| `Cmd + D` | Add selection to next find match |
| `Cmd + Shift + L` | Select all occurrences of current selection |
| `Ctrl + Shift + Cmd + Left / Right` | Expand / shrink selection |

## Navigation

| Shortcut | Action |
|----------|--------|
| `Cmd + T` | Show all symbols |
| `Cmd + G` | Go to line |
| `Cmd + Shift + O` | Go to symbol in file |
| `Cmd + Shift + M` | Show problems panel |
| `F8` | Go to next error or warning |
| `Shift + F8` | Go to previous error or warning |
| `Ctrl + -` | Go back |
| `Ctrl + Shift + -` | Go forward |
| `Ctrl + Tab` | Navigate editor group history |

## Search and Replace

| Shortcut | Action |
|----------|--------|
| `Cmd + F` | Find |
| `Cmd + H` | Replace |
| `Cmd + G` | Find next |
| `Cmd + Shift + G` | Find previous |
| `Cmd + Shift + F` | Search across files |
| `Cmd + Shift + H` | Replace across files |
| `Cmd + E` / `Cmd + Shift + E` | Use selection for find |

## Multi-cursor and Selection

| Shortcut | Action |
|----------|--------|
| `Option + Click` | Insert cursor |
| `Option + Cmd + Up / Down` | Insert cursor above / below |
| `Cmd + U` | Undo last cursor operation |
| `Shift + Option + I` | Insert cursor at end of each line selected |
| `Cmd + I` | Select current line |
| `Cmd + Shift + \` | Jump to matching bracket |

## Editor Management

| Shortcut | Action |
|----------|--------|
| `Cmd + W` | Close editor |
| `Cmd + K W` | Close all editors in group |
| `Cmd + \` | Split editor |
| `Cmd + 1 / 2 / 3` | Focus into 1st / 2nd / 3rd editor group |
| `Ctrl + 1 / 2 / 3` | Focus into 1st / 2nd / 3rd editor group |
| `Cmd + K Cmd + Left / Right` | Focus previous / next editor group |
| `Cmd + K Cmd + Shift + Left / Right` | Move editor left / right |
